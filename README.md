面向 Python 初学者的基础教程与练习资料整理。内容从基础语法出发，逐步覆盖数据类型、流程控制、函数、标准库、异常处理与数据库入门，适合作为自学路线和快速复习手册。

> 先跑起来，再理解原理；一次学一个知识点，并把示例改成自己的版本。

## ✨ 你可以学到

- Python 基础语法、注释、变量与常用运算符
- 字符串、列表、字典等常用数据类型
- if、for、while、break 与 continue
- 函数、内置函数与第三方库的使用
- os、sys、urllib、requests、datetime、json 等常用模块
- pip、异常处理与 SQLite 数据库基础

## 🚀 如何使用

1. 安装 [Python 3](https://www.python.org/downloads/)。
2. 按下方目录顺序阅读每一节内容。
3. 在本地重新输入并运行示例，不要只复制粘贴。
4. 修改参数、补充注释，并记录运行结果。
5. 每学完一个单元，用一个小练习把知识串起来。
